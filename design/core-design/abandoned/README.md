# Abandoned ideas

Design that was ruled on, built on, and then dropped when the direction changed.

**Nothing in this directory is current.** It is not linked from the map's *Decisions so far*, and no
session should read it to find out what the game is. The map and `CONTEXT.md` are the only places
that say what is true now.

It exists for one reason: the map's provenance rule. Previous attempts at this design lost track of
which ideas were the designer's and which were an LLM's, and deleting a body of work outright throws
that record away along with the reasons it was dropped. So an abandoned idea keeps its `[you]` /
`[proposed by agent → you approved]` tags and gains one line saying what superseded it.

Open a file here only when a ticket sends you to it by name.
