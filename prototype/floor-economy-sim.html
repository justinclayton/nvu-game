The card set in this simulator is a placeholder, so no number it reports is a finding. Ticket 12 has not built the exemplar cards yet. Until it does, this tool is a rules engine waiting for cards: win rates, deck sizes and threshold curves it prints are properties of the stand-in cards in CARD_SET, not of North vs Up. What it is good for now is checking that a rule behaves — see the Model tab.

Neither the cards nor the threshold dials have been tuned against each other, deliberately — tuning placeholders to each other is how the last version produced numbers that looked like answers. So most runs fail out around the middle floors. That is the untuned default, not a broken engine.
