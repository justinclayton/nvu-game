North vs Up — card editor

Every field on a card is live: click it and type. Tab moves through a card. Add a card with the dashed tile at the end of a section; remove, duplicate or revert from the row under each card. A gold ring is an edited card, green is new, red has a problem the card generator would reject (the message under the card says what); a yellow note is a line the engine can't read yet, which the PR plans as code. Your draft is kept in this browser until you send it or discard it. When you are done, open changes in the top bar. In Lavish, Queue for agent then Send to Agent and the agent writes the batch into cards.yaml. On your own, Download changes.json and run node tools/card-editor.mjs apply changes.json.
